## 1. Роли и целевые аудитории

| Роль | Описание |
|---|---|
| **Учащийся 9–11 класса** | Главный пользователь. Выбирает IT-направление, записывается на профпробу, проходит занятие очно или дистанционно и получает результат. |
| **Родитель** | Помогает принять решение об участии, оплате и дальнейшем выборе курсов, ЕГЭ или вуза. |
| **Наставник** | Проводит профпробу, объясняет задачу, помогает участникам и фиксирует результат. |
| **Администратор платформы** | Управляет профпробами, расписанием, пользователями и качеством контента. |
| **Организатор площадки** | Предоставляет место для очных профпроб: IT-школа, образовательный центр, школа, вуз или технопарк. |

## 4. MVP и MLP

### MVP

MVP — минимальная версия продукта, которая позволяет проверить основной сценарий:

**участник выбирает профпробу, записывается, проходит занятие и получает результат.**

| № | История | Почему входит в MVP |
|---|---|---|
| 1 | Регистрация на платформе | Позволяет участнику записываться на профпробы и получать результаты в личном профиле. |
| 2 | Выбор IT-направления | Без выбора направления профпроба невозможна. |
| 4 | Просмотр формата профпробы | Участник должен понимать, как будет проходить занятие: очно или дистанционно. |
| 5 | Просмотр даты, времени и места | Критично для очного и дистанционного формата. |
| 6 | Запись на свободное место | Главная функция платформы. |
| 7 | Подтверждение записи | Пользователь должен получить подтверждение участия. |
| 9 | Прохождение практического задания | Главная ценность продукта. |
| 10 | Получение результата после профпробы | Завершает основной пользовательский путь. |
| 16 | Внесение итога наставником | Позволяет участнику получить персональный результат после занятия. |

### MLP

MLP — функции, которые делают продукт удобнее, понятнее и приятнее, но не являются обязательными для первой версии.

| № | История | Почему входит в MLP |
|---|---|---|
| 3 | Описание направления | Помогает лучше понять профессию до записи. |
| 8 | Напоминание о профпробе | Уменьшает риск неявки. |
| 11 | История пройденных профпроб | Позволяет возвращаться к результатам и сравнивать разные направления. |
| 12 | Понятная информация о профпробе для родителя | Повышает доверие к сервису. |
| 13 | Просмотр результата родителем | Позволяет родителю увидеть, какие задания выполнял ребёнок, что получилось хорошо, что вызвало трудности и какой вывод дал наставник. |
| 14 | Список участников для наставника | Помогает подготовиться к занятию. |
| 15 | Отметка присутствующих | Помогает вести точный учёт участников, но в MVP может быть частью внесения результата. |
| 17 | Создание и редактирование профпроб | Нужно для масштабирования каталога. |
| 18 | Управление расписанием | Нужно при большом количестве занятий и площадок. |

## 5. Детализация требований

Для детализации выбраны две главные истории из MVP:

1. Запись на профпробу.
2. Получение результата после профпробы.

---

## История 1. Запись на профпробу

**User Story:**  
Как учащийся, я хочу записаться на свободное место в профпробе, чтобы гарантировать своё участие в очном или дистанционном занятии.

### Функциональные требования

| № | Требование |
|---|---|
| ФТ-1 | Пользователь может открыть каталог доступных профпроб. |
| ФТ-2 | Система показывает для каждой профпробы название, IT-направление, формат, дату, время, длительность и количество свободных мест. |
| ФТ-3 | Пользователь может открыть карточку профпробы и посмотреть подробное описание занятия. |
| ФТ-4 | Пользователь может выбрать доступный слот и нажать кнопку “Записаться”. |
| ФТ-5 | Система проверяет наличие свободных мест перед подтверждением записи. |
| ФТ-6 | После успешной записи система закрепляет место за пользователем. |
| ФТ-7 | Пользователь получает подтверждение записи с датой, временем, форматом и адресом или ссылкой для подключения. |
| ФТ-8 | Система сохраняет запись в личном профиле пользователя. |
| ФТ-9 | Если свободных мест нет, система показывает сообщение о невозможности записи и предлагает выбрать другой слот. |
| ФТ-10 | Пользователь может отменить запись до начала профпробы. |

### Нефункциональные требования

| № | Требование |
|---|---|
| НФТ-1 | Для авторизованного пользователя с заполненным профилем процесс записи на профпробу должен занимать не более 3 минут. |
| НФТ-2 | Система не должна допускать записи сверх установленного лимита участников. |
| НФТ-3 | Информация о свободных местах должна быть актуальной на момент подтверждения записи. |
| НФТ-4 | Интерфейс записи должен корректно работать на смартфонах и компьютерах. |
| НФТ-5 | Время загрузки карточки профпробы не должно превышать 2 секунд при нормальном интернет-соединении. |
| НФТ-6 | Данные пользователя и информация о записи должны храниться безопасно. |
| НФТ-7 | Адрес очного занятия и ссылка на дистанционное подключение должны отображаться понятно и без двусмысленности. |

---

## История 2. Получение результата после профпробы

**User Story:**  
Как учащийся, я хочу получить результат после профпробы, чтобы понять, что мне понравилось, что было сложно и стоит ли дальше изучать это направление.

### Функциональные требования

| № | Требование |
|---|---|
| ФТ-1 | Наставник может открыть список записавшихся участников. |
| ФТ-2 | Наставник может выбрать участника, который прошёл профпробу. |
| ФТ-3 | Наставник может открыть карточку участника для внесения результата. |
| ФТ-4 | Наставник заполняет результат профпробы: что получилось хорошо, что вызвало трудности и общий вывод по занятию. |
| ФТ-5 | Система сохраняет заполненный наставником результат. |
| ФТ-6 | Пользователь может открыть результат в личном профиле. |
| ФТ-7 | Результат содержит краткий вывод: что получилось хорошо, что вызвало трудности и стоит ли дальше изучать это направление. |
| ФТ-8 | Наставник может внести результат только для участника, который был записан на эту профпробу. |

### Нефункциональные требования

| № | Требование |
|---|---|
| НФТ-1 | Результат должен быть доступен пользователю не позднее чем через 24 часа после окончания занятия. |
| НФТ-2 | Формулировки результата должны быть понятны учащемуся и родителям без технического образования. |
| НФТ-3 | Результаты профпроб должны быть доступны только авторизованному пользователю. |
| НФТ-4 | Экран результата должен корректно отображаться на мобильных устройствах и компьютерах. |
| НФТ-5 | Результаты профпроб должны сохраняться, чтобы пользователь мог вернуться к ним позже. |
